# WinScript Doctor 디자인 기준

사용자 지정 스택은 Wails + Go + React·TypeScript + Tailwind CSS + shadcn/ui입니다. 디자인 기준은 로컬에서 활성화가 확인된 k-style-ui-ux@memorylove-design 0.17.1의 principles.md와 COMPONENTS.md를 사용합니다. 별도 kdesign MCP 호출 결과로 표시하지 않습니다.

## 사용자 흐름

장애를 확인하는 운영자는 작업과 연결된 스크립트 선택 → 진단 근거 → 환경 비교 → 다음 확인 방법 순서로 진행합니다. 인수인계 상황에서는 자산 검색 → 예약 작업 확인 → 파일 위치·진단 확인 → 저장 결과 전달 순서로 진행합니다.

각 화면은 하나의 h1, 검색 가능한 목록, 일관된 선택 표시, 같은 위치에서 열고 닫는 진단 근거를 제공합니다. 버튼과 메뉴는 실제 구현된 동작만 표시합니다.

## 토큰과 shadcn 대응

`frontend/src/styles.css`의 공통 토큰을 Tailwind theme과 shadcn/ui에 대응시킵니다. 설치된 컴포넌트는 공식 shadcn CLI 4.22.0에서 생성한 소스이며, 제품 공통 cn 유틸리티와 한국어 레이블에 맞게 조정했습니다.

| 역할 | CSS 변수 | 사용처 |
| --- | --- | --- |
| 주 행동과 선택 | primary, primary-soft | 버튼·현재 메뉴·선택한 행·선택 필터 |
| 배경과 콘텐츠 | background, card, foreground | 창·패널·본문 |
| 보조 정보 | muted-foreground, border | 수집 시각·경계·설명 |
| 주의 | warning, warning-soft | 확인 필요·관측한 차이 |
| 실패 | destructive, destructive-soft | 처리 실패·실행 불가 |
| 완료 | success, success-soft | 완료·현재 비교에서 동일 |
| 안내 | info, info-soft | 미확인·추가 확인 |

근거 상태는 원인 후보·직접 관측·미확인으로 표시합니다. 관측한 차이가 장애 원인으로 확정됐다는 인상을 주지 않습니다. 같은 진단은 두 화면에서 같은 문구와 상태 의미를 사용합니다.

색은 제품 전용 청록색과 중립색을 사용합니다. 기존 국내 브랜드의 사진·로고·팔레트를 복사하지 않습니다. 아이콘은 Lucide의 개별 아이콘을 사용합니다. 웹폰트·원격 이미지·차트 장식·배경 블러는 사용하지 않습니다.

## 레이아웃과 접근성

권장 창은 1440×980, 최소 창은 1024×720입니다. 넓은 화면에서는 목록과 진단 상세를 나란히, 좁은 화면에서는 상세를 목록 아래 배치합니다. 헤더와 상태 표시줄을 유지하고 본문만 스크롤합니다.

키보드 초점·선택 상태·색과 함께 제공되는 텍스트 레이블을 포함합니다. 한국어 제목은 단어 단위로 줄바꿈하고 긴 경로는 별도 줄바꿈 규칙으로 표시합니다. 시스템 글꼴을 사용하며 표에서 수집되지 않은 값은 미확인으로 남깁니다.

검증 범위는 docs/verification.md에 기록합니다. Windows Server의 실제 RDP와 125·150·200퍼센트 DPI 검증은 아직 수행하지 않았습니다.
