# 첫 화면 구현 검증 기록

검증일은 2026년 11월 3일이며 현재 PC의 Windows 11 환경에서 수행했습니다.

## 통과한 검증

| 항목                   | 결과                                                                |
| ---------------------- | ------------------------------------------------------------------- |
| Windows 프로덕션 빌드  | 성공. bin/WinScriptDoctor.exe, 10,995,200 bytes, 약 10.49 MiB       |
| Go 테스트              | go test ./... 통과                                                  |
| 프런트엔드 데이터 검증 | Vitest 34개 통과                                                    |
| 사용자 흐름            | Microsoft Edge에서 Playwright 8개 통과                              |
| 네이티브 연결          | Wails 창에서 Go 서비스 호출, 비교 8개 항목·차이 6개·미확인 1개 확인 |
| 개발 실행              | scripts/dev.ps1로 Vite와 Wails 창 기동 및 Go 호출 확인              |
| 프런트엔드 번들        | JS 합계 gzip 약 128.36 kB, CSS gzip 약 9.98 kB                      |
| 외부 요청              | 메인·비교 화면의 브라우저 테스트에서 외부 네트워크 요청 없음        |
| 창 크기                | 1440×1000 및 1024×768에서 가로 넘침 없음                            |

환경은 Go 1.27.3, Wails 3.1.0, Node 24.19.0, WebView2 156.0.4314.58입니다. 도구 버전과 의존성은 Go 모듈 및 npm 잠금 파일에 기록했습니다.

## 사용자 흐름 테스트

1. 검색과 상태 필터, 빈 결과, 선택한 스크립트의 진단 표시
2. 차이·미확인 필터, 비교 작업 선택과 좌우 전환
3. 테마 보존과 최소 창 크기의 가로 넘침 확인
4. 잘못된 JSON 거부와 정상 스냅샷 가져오기
5. 저장한 JSON을 다시 가져오는 흐름
6. 두 화면의 런타임 오류·외부 요청 확인
7. 같은 작업에 연결된 다른 스크립트의 비교 자료 오연결 방지
8. 가져오기 취소 후 늦은 비동기 결과가 다시 표시되지 않음

데이터 테스트는 지원하지 않는 필드, 중복 ID, 잘못되거나 모호한 참조, 상태와 진단의 모순, 입력 크기 제한, 원문 비밀값이 오류에 포함되지 않음, 미확인 건수, Windows 경로 정규화와 모듈 경로의 순서 보존을 확인합니다. 큰 결과의 compact JSON 저장 후 재열기 회귀 사례도 포함합니다.

## 후속 검증

Windows Server와 RDP·125·150·200퍼센트 DPI 조합은 아직 확인하지 않았습니다. 개발 중 현재 PC의 화면 크기 검증을 해당 서버 호환성으로 간주하지 않습니다.

실제 서버 수집, 예약 작업 진단 프로브, 자동 수정과 HTML 보고서 생성은 아직 구현하지 않았습니다. 시작 시간, 전체 프로세스 메모리와 CPU, 1천 개 자산의 성능 목표도 후속 단계에서 별도로 측정합니다. 현재 실행 파일 및 프런트엔드 번들 크기를 전체 런타임 비용으로 해석하지 않습니다.

이 최초 화면 검증 당시에는 기존 Git 브랜치와 원격을 변경하지 않았으며 커밋·푸시를 수행하지 않았습니다.

## macOS·Linux 설치 경로 추가 검증

같은 날 Windows 11에서 공통 기능과 패키징을 다시 검증했습니다.

| 항목                                 | 결과                                                                                                         |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| Go 테스트                            | go test ./... 통과                                                                                           |
| 프런트엔드 데이터·네이티브 연결 검증 | Vitest 36개 통과. WebView2와 WebKit 메시지 핸들러 각각의 서비스 호출 확인                                    |
| 사용자 흐름                          | Microsoft Edge에서 Playwright 8개 통과                                                                       |
| 플랫폼별 패키지 구성                 | Node 테스트 5개 통과. macOS 번들·아이콘·최소 OS, Linux 파일·Debian 의존성·CPU 정보, 임시 폴더 정리 범위 확인 |
| Windows 배포 파일                    | 프로덕션 빌드 및 포터블 ZIP·SHA256 생성 성공                                                                 |
| POSIX 스크립트                       | Git에 포함된 sh로 설치·빌드·개발·테스트 스크립트 구문 검사 통과                                              |
| 프런트엔드 번들                      | JS 합계 gzip 약 128.41 kB, CSS gzip 약 10.00 kB                                                              |

WebKit 테스트는 메시지 핸들러를 모사한 단위 테스트입니다. 패키지 구성 테스트도 합성 실행 파일을 사용하므로 실제 macOS·Linux 실행의 증거로 간주하지 않습니다. 현재 PC에는 해당 OS의 네이티브 빌드·GUI 환경이 없어 실제 컴파일·설치·실행은 미확인입니다.

Windows, Ubuntu 24.04, Apple Silicon Mac, Intel Mac 각각에서 빌드·테스트·패키징할 수동 GitHub Actions 워크플로를 준비했습니다. 이 검증은 로컬 결과이며 GitHub Actions 실행 결과를 포함하지 않습니다. macOS 패키지는 로컬용 ad-hoc 서명이며 Developer ID 서명·공증은 포함하지 않았습니다. [운영체제별 설치 안내](installation.md)에 실행 조건과 확인 범위를 기록했습니다.

## 공개 준비 검증

사용자의 공개 저장소 게시 요청에 따라 한·영 README, 개발 로드맵, 기여 안내와 이슈·PR 양식을 추가했습니다. 생성된 shadcn/ui 코드의 원본 라이선스도 보존하고 패키지 구성 테스트에서 포함 여부를 확인합니다.

npm audit --omit=dev 실행 결과 알려진 취약점 0개가 보고되었습니다. 이는 해당 시점 npm 운영 의존성의 감사 결과이며, Go 의존성이나 앱 전체의 보안 검증을 대신하지 않습니다. 실제 운영 스냅샷, 인증 파일, 비밀키·인증서, 로컬 실행 파일과 의존성 폴더는 공개 소스에 포함하지 않습니다.
